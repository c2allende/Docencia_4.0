Ventajas del Diseño Compacto

  • Eficiencia Espacial: Reduce el scroll vertical en un ~60% cuando los elementos están colapsados.
  • Enfoque en el Título: Permite al usuario escanear títulos rápidamente sin distraerse con los resúmenes.
  • Accesibilidad Nativa: Utiliza el elemento HTML <details>, garantizando soporte para lectores de pantalla sin JavaScript adicional.
  • Interacción Intuitiva: El indicador visual (flecha) y el cambio de estado en hover/open mejoran la experiencia de usuario (UX).

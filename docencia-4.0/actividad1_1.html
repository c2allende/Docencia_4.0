Ejercicio: "Hola mundo pedagógico"

Objetivo

Lograr el primer acceso exitoso a un LLM, configurar privacidad y generar un producto útil en < 5 minutos.

Detalles

Duración: 30-40 minutos | Requisitos: Dispositivos con internet.

Instrucciones del Taller

Sigue estos pasos para completar tu primera interacción guiada con un Modelo de Lenguaje de Gran Tamaño:

🚀

Acceso

Entra al LLM seleccionado (ChatGPT, Microsoft Copilot o Google Gemini) utilizando tu cuenta institucional o personal autorizada.

🔒

Privacidad

Configura las opciones básicas de protección de datos: asegúrate de desactivar el entrenamiento con tus datos si la plataforma lo permite y verifica que no estás ingresando PII.

📝

Generación

Crea un producto pedagógico inmediato (un plan de clase simple, una lista de 5 ejemplos para un tema complejo o un borrador de correo). ¡Experimenta con el resultado!

# Archivo de páginas no oficiales — Docencia 4.0

Esta carpeta contiene prototipos, versiones QA, páginas de uniformidad, pruebas visuales y copias no oficiales del LMS Docencia 4.0.

## Propósito

Separar los archivos no oficiales de las páginas activas de producción local para evitar confusión durante QA, commit y deploy.

## Regla operativa

Los archivos dentro de esta carpeta no se consideran páginas oficiales del LMS.

No deben enlazarse desde navegación, dashboard, módulos, lecciones, actividades, recursos o foros oficiales.

## Categorías

- `prototipos_actividades/`
- `prototipos_plantillas/`
- `prototipos_lecciones/`
- `prototipos_modulos/`
- `prototipos_recursos_foros/`
- `prototipos_dashboard/`
- `otros_no_oficiales/`

## Fecha de organización

Organizado durante la fase final de migración controlada a producción local.

## Nota

No eliminar estos archivos sin autorización explícita. Funcionan como historial de trabajo y respaldo visual.

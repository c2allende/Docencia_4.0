Mantenimiento y Limpieza de Pruebas

Esta herramienta permite al administrador limpiar datos de prueba generados durante procesos de QA, talleres y validaciones internas. No elimina contenido académico ni usuarios del sistema.

⚠️ Use esta herramienta únicamente después de verificar que los datos corresponden a pruebas. Las acciones de limpieza son irreversibles.

Board Actividad 1.1

Limpia las respuestas de prueba registradas en el board interactivo de la Actividad 1.1. Todos los registros actuales serán eliminados permanentemente.

Listo para revisar.

Progreso LMS de prueba

Limpia el progreso asociado a un usuario de prueba específico introduciendo su correo electrónico.

Esperando correo.

Foros de prueba

Permite revisar y limpiar publicaciones de prueba en foros, si existen colecciones identificadas.

Esta función requiere que las publicaciones tengan el atributo isTest para operar de manera segura. Bloqueado temporalmente.

Anuncios de prueba

Limpia únicamente anuncios identificados como pruebas en la base de datos general de anuncios.

No se puede limpiar automáticamente porque los anuncios no están marcados como prueba.

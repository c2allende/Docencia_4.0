Actividad 2.1: Taller práctico: "Del prompt al recurso validado"

Ejercicio: "Hola mundo pedagógico"

Objetivos de la actividad

  • Diseñar prompts efectivos usando la fórmula Rol + Contexto + Tarea + Formato + Restricciones.
  • Generar una planificación semanal y un recurso didáctico a partir de un estándar real del DEPR.
  • Validar críticamente los materiales generados utilizando una Lista de Cotejo de Validación Curricular.
  • Refinar prompts de manera iterativa para mejorar la calidad e inclusión.

Ficha del Taller

⏱️ Duración: 60 minutos

💻 Requisitos: Dispositivos con internet.

📚 Materiales: Estándares DEPR, Acceso a LLM (ChatGPT/Copilot).

Pasos para el Taller

🎯

Fase 1: Diseño de Prompt

Aplica la fórmula aprendida para solicitar a la IA una estructura de clase basada en un estándar específico de tu materia.

⚙️

Fase 2: Generación de Recursos

Interactúa con el LLM para producir tanto la planificación como un material complementario (ejercicio, lectura o rúbrica).

✅

Fase 3: Validación Curricular

Utiliza la lista de cotejo para verificar que el contenido sea preciso, culturalmente pertinente y libre de sesgos.

Muro Colaborativo de Resultados

Publica aquí tus prompts más exitosos o los recursos validados que has generado. Observa y comenta los trabajos de tus colegas.
